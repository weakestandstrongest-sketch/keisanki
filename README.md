# MATHSCAPE

**A new way to interact with numbers.**

数字・数式・条件・可能性を自由に操作できる、自分だけの計算空間。
普通の計算機として使えますが、答えは「ただの答え」で終わりません。

## できること

| 操作 | 内容 |
| --- | --- |
| 計算 | 四則演算、`( )`、`^`、`√`、`x²`、`%`、`mod`、`π`、`!`。キーボード入力にも対応 |
| **ぷに化** | 答えを、ぷにぷにした数字の玉 (ソフトボディ) にして空間に浮かべる |
| **タップして調べる** | ぷに・答え・履歴をタップすると、その数を 5 つの方法で探索 |
| **重ねて計算** | ぷにをドラッグして別のぷにに落とすと `+ − × ÷ ^ mod gcd lcm 平均 つなげる` から選んで合体 |
| 計算機へ戻す | ぷにを計算機パネルへドラッグすると式に入る |
| スマホの計算機 | 画面下のつまみを上に引っ張ると計算機が出てくる。下げると空間に戻る |
| 無重力 | 重力を切って、ぷにをふわふわ漂わせる |
| **ホログラム** | 光る台座の上で、空間の数字が結晶になる立体ビュー。結晶をタップで選ぶと、浮かぶパネルに桁・余り・性質が映る。ドラッグで回転。`#holo` 付きの URL で直接開ける |
| ホログラム (スマホ) | 全画面表示。傾けて回す、はじいて結晶を選ぶ、3 枚のパネルが周りに浮かび、長押しで正面に大きく、2 本指で拡大。計算すると答えが光になって結晶になる |

### 数を調べる 5 つのタブ

- **分解** — 位取り、素因数分解、約数、掛け算・足し算への分解 (素数+素数、平方数の和、2 の累乗の和)、小数→分数
- **変換** — 2/8/16/36 進数、漢数字、ローマ数字、指数表記。長さ・重さ・時間・温度・データ・速さ・面積・角度などの単位
- **生成** — 2 乗、√、逆数、階乗、n 番目の素数/フィボナッチ数、倍数、べき乗、乱数…(どのチップもタップでぷに化、› でさらに調べる)
- **シミュ** — 複利/単利の成長・減衰、コイン・サイコロの確率実験、誕生日のパラドックス、コラッツの旅
- **可視化** — 量のドット、関連データとのスケール比較、同じ面積の長方形、ビット、桁の虹、小数部の円

## 動かし方

ビルド不要の静的サイトです。`index.html` をブラウザで開くか、ローカルサーバーで配信してください。

```bash
python3 -m http.server 8000
```

`http://localhost:8000` を開きます。GitHub Pages にもそのまま置けます。

## 構成

```
index.html
style.css
js/format.js     数値の表示 (万・億・兆 など)
js/numlab.js     素因数分解・約数・単位変換などの計算
js/calc.js       式パーサと計算機 UI
js/blobs.js      ぷにぷに (シェイプマッチング + 内圧のソフトボディ物理)
js/inspector.js  分解・変換・生成・シミュ・可視化パネル
js/holo.js       ホログラム・ビュー (アイソメトリック投影の 3D 描画)
js/app.js        全体の結線 (ドラッグ、合体、ショートカット)
```
